# 🌤️ Forecatrip

**Forecatrip** is a smart trip-planning platform that helps users find travel suggestions based on:

- Location
- A selected date within the upcoming week
- Type of participants (friends, family, couples)

The system analyzes real-time weather forecasts and recommends personalized trips that match the expected conditions and group preferences.

---

## ✨ Features

- ⛅ Weather-based recommendations
- 🧍‍♀️ Group-based customization
- 🗺️ Nearby trip suggestions
- 📅 Quick and easy trip planning

---

## 🛠️ Technologies Used

- HTML, CSS, JavaScript (or React/Vue/etc.)
- Node.js / Express (if backend is used)
- Weather API (e.g., OpenWeatherMap)
- Google Maps or custom location service
